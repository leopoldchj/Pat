# Project conventions

patterns, naming) are maintained in a single tool-agnostic file at the repo
root: **`AGENTS.md`**.

Read and strictly follow `AGENTS.md` before generating or modifying any code.
Do not duplicate its content here — it is the single source of truth shared by
Kiro, Claude Code and Codex.
